Можливості

doQumentation перетворює відкриті матеріали IBM Quantum на інтерактивну навчальну платформу з виконанням коду наживо, IBM Cloud Code Engine, режимом симулятора, відстеженням прогресу навчання та підтримкою багатьох мов.

Структурована навігація

Автоматично згенерована бічна панель зі згортними розділами для туторіалів, посібників, курсів і модулів та з лічильниками прогресу.

Виконання коду наживо

Перемикач «Запустити / Назад»

На кожній сторінці ноутбука є кнопка «Запустити», яка активує всі комірки коду з живим ядром Jupyter. Натисни «Назад», щоб повернутися до статичного перегляду.

Чотири бекенди виконання

Безкоштовне віддалене виконання через Binder або Google Colab, швидкі безсерверні ядра через IBM Cloud Code Engine або повністю офлайн через Docker і RasQberry Pi. Якщо доступно кілька бекендів, обери потрібний на сторінці налаштувань.

Configure backend →

IBM Cloud Code Engine

Безсерверне ядро Jupyter у твоєму акаунті IBM Cloud, без спільної черги: холодний старт за лічені секунди (Binder зазвичай потребує менше хвилини, а при холодному старті — до 3 хвилин). Безкоштовний рівень покриває приблизно 14 годин на місяць.

Налаштувати Code Engine →

Режим воркшопу

Проводь аудиторні воркшопи з участю до 50 учасників. Розгорни кілька екземплярів Code Engine і поділись єдиною URL — учасники розподіляються автоматично зі sticky sessions та автоматичним failover.

Посібник з налаштування воркшопу →

Моніторинг воркшопу

Живий дашборд з автооновленням (30 с) відображає кількість ядер, активні ядра, підключення, використання пам'яті та час роботи по кожному екземпляру. Кожен екземпляр надає ендпоінт /stats. Скрипт стрес-тесту імітує одночасних користувачів для виявлення лімітів потужності до початку заняття.

Дашборд налаштувань →

Colab

На кожній сторінці з ноутбуком є кнопка «Відкрити в Colab» для виконання в хмарі без встановлення. Відкриває перекладені ноутбуки при перегляді іншою мовою.

Індикація виконання комірок

Візуальний відгук для кожної комірки: бурштинова рамка під час виконання, зелена після завершення, червона у разі помилки. Коли ядро готове, на панелі інструментів з'являється легенда.

Контекстні підказки щодо помилок

Автоматичне виявлення ModuleNotFoundError, NameError і від'єднання ядра. Під коміркою з'являються практичні підказки із запропонованими виправленнями. Кожна помилка містить посилання «Повідомити про цю помилку», яке відкриває попередньо заповнене звернення на GitHub.

Встановлення через pip одним кліком

Коли виявлено відсутній пакет, з'являється кнопка «Встановити». Після завершення встановлення комірка, яка завершилася помилкою, автоматично запускається повторно.

Відкрити в JupyterLab

Відкрий будь-який ноутбук у повноцінному JupyterLab. Запуски Binder показують відстеження фаз у реальному часі з таймером і попередженнями про промах кешу. Скасуй у будь-який момент або отримай сповіщення про повільну фазу з порадою швидших бекендів. Наступні кліки миттєво використовують той самий сервер.

Запустити все та перезапустити

«Запустити все» виконує всі комірки по порядку з живим лічильником прогресу. Зупинись після поточної комірки будь-коли. «Перезапустити» дає свіже ядро без втрати сесії Binder.

Інтеграція з IBM Quantum

Сховище облікових даних

Збережи свій API-токен IBM Quantum і CRN один раз у налаштуваннях. Вони зберігаються локально у твоєму браузері та для безпеки автоматично спливають через 7 днів.

Налаштувати облікові дані →

Автоматична підстановка

Облікові дані непомітно підставляються в ядро під час запуску. Не потрібно вставляти токени в кожен ноутбук — просто натисни «Запустити».

Режим симулятора

Запускай усі ноутбуки без акаунта IBM Quantum. Обери AerSimulator для ідеальної симуляції або одну з десятків FakeBackends, що моделюють шум реальних пристроїв. Жодного налаштування.

Увімкнути симулятор →

Позначка режиму виконання

Панель інструментів показує активний режим — назву симулятора (наприклад, «FakeSherbrooke») або «IBM Quantum» — тож ти завжди знаєш, як виконується твій код.

Твій прогрес

Відстеження прогресу

Відвідані сторінки отримують позначку (✓) на бічній панелі. Виконані ноутбуки отримують індикатор запуску (▶). Відстежуй свій шлях матеріалами.

Позначки категорій

Кожна категорія на бічній панелі показує позначку на кшталт «3/10», щоб прогрес було видно одразу. Натисни, щоб очистити прогрес розділу.

Продовжити читання

Головна сторінка показує картку «Продовжити з того місця, де ти зупинився» з твоєю останньою відвіданою сторінкою та часом візиту.

Поради при першому запуску

Багатомовність

Підтримка багатьох мов

Весь сайт доступний багатьма мовами, зокрема німецькою, японською, іспанською, французькою та іншими. Кожна мова працює на власному субдомені з перекладеним інтерфейсом.

Автоматичний резервний варіант

Неперекладені сторінки відображаються англійською з банером мовою читача, щоб жодна сторінка не була відсутня.

Пошук, інтерфейс і розгортання

Локальний пошук

Повнотекстовий пошук по всіх сторінках працює офлайн. Результати з'являються миттєво, поки ти друкуєш.

Темний режим

Повна підтримка темної теми. Схеми кіл і виводи Matplotlib автоматично інвертуються для кращої читабельності.

Вбудовані відео

Відео курсів із відповідністю до YouTube для надійного відтворення. Якщо YouTube недоступний, використовується IBM Video.

Розгортання через Docker

Багатоетапна збірка Docker з CI/CD до GitHub Container Registry: один образ із сайтом, Jupyter і Qiskit для офлайн-використання та навчальних класів.

Адаптивність для мобільних

Навігація-гамбургер, горизонтальне прокручування коду та адаптивні сітки карток. Працює на телефонах і планшетах.

Відображення формул

KaTeX забезпечує швидке й якісне відображення математики LaTeX на всіх сторінках — рівняння, матриці та квантові позначення.
