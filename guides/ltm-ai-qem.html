AI-QEM від LTM

примітка

IBM Quantum® Functions — це бета-функція, доступна лише користувачам IBM Quantum Premium Plan, Flex Plan та On-Prem (через IBM Quantum Platform API) Plan. Бета-функції можуть змінюватися.

Див. довідник API.

Поточні обмеження

Поточний випуск AI-QEM має такі обмеження:

  • Пом'якшення обмежене родиною процесорів Heron. LTM планує підтримати додаткові бекенди в майбутніх версіях.

  • Пом'якшення помилок застосовується вибірково. Пом'якшення виконується лише тоді, коли абсолютне значення очікування задовольняє ∣⟨O⟩noisy∣≥0.1|\langle O \rangle_{noisy}| \geq 0.1∣⟨O⟩noisy​∣≥0.1, щоб воно застосовувалося лише там, де очікується змістовна користь.

Ці обмеження відображають поточний обсяг можливостей AI-QEM. Майбутні випуски можуть їх послабити, коли LTM додасть підтримку додаткових робочих процесів, бекендів і функцій.

Огляд​

Пом'якшення квантових помилок (QEM) охоплює алгоритмічні протоколи, такі як екстраполяція до нульового шуму (ZNE) [2] і ймовірнісне скасування помилок (PEC) [3], призначені для придушення зсуву, спричиненого шумом, у значеннях очікування на зашумленому обладнанні проміжного масштабу (NISQ), без великих накладних витрат кубітів, потрібних для повної відмовостійкості. Ці методи критично важливі для отримання надійних фізичних симуляцій і результатів бенчмарків на сучасних процесорах. Хоча в останні роки розроблено багато методів QEM, майже всі вони мають фундаментальний компроміс: для досягнення точності вони потребують значно більше часу QPU. Їхнє визначальне обмеження — експоненційні накладні витрати на вибірку, адже відновлення незміщеного сигналу із зашумлених кіл значно збільшує статистичну дисперсію оцінювача. Отже, подолання вищих рівнів шуму потребує на порядки більше вимірювальних шотів, що призводить до значно довшого часу роботи QPU і суттєвих апаратних вузьких місць [4, 5, 6].

За допомогою AI-QEM ти можеш запускати квантові кола на зашумлених QPU і отримувати покращені значення очікування порівняно з іншими методами пом'якшення помилок на основі ШІ, без жодних додаткових накладних витрат часу QPU. Підхід використовує глибоку нейронну мережу з архітектурою графової згорткової мережі (GCN)-Transformer. Мережу навчають на ознаках, що містять структуру кола, топологію бекенда, спостережувані Паулі та калібрування кубітів, і вона передбачає поправковий коефіцієнт, позначений ζ\zetaζ. Ділення зашумленого значення очікування на ζ\zetaζ дає покращене значення очікування. Експерименти показують, що AI-QEM дає кращі результати, ніж інші методи пом'якшення на основі ШІ, особливо для кіл великої глибини (шарів вентилів) і ширини (кількості кубітів), що робить його добре придатним для квантових експериментів корисного масштабу. Таблиця в розділі Бенчмарки показує, що модель на основі GCN-Transformer перевершує моделі на основі випадкового лісу (RF) у діапазоні від 80 до 150 кубітів із середньою абсолютною похибкою (MAE) 0.343. MAE — це середнє, за великою кількістю конфігурацій кіл і спостережуваних, абсолютної різниці між ідеальним значенням очікування та значенням очікування після того, як модель пом'якшила зашумлений результат обладнання. Крім того, оскільки модель не залежить від кола, ти можеш застосовувати її до широкого спектра квантових кіл і застосувань без спеціальної адаптації під конкретне коло.

Повний опис базових компонентів і демонстрацію корисного масштабу дивись у статті про AI-QEM [1].

Опис​

Використовуй функцію LTM AI-QEM, щоб оцінити значення очікування спостережуваних для заданого квантового кола. Щоб скористатися LTM AI-QEM, надай квантове коло, набір спостережуваних для вимірювання та QPU. Функція використовує той самий час QPU, що й примітив IBM Quantum Estimator, і жодного додаткового часу QPU.

Звичайний спосіб обчислити значення очікування спостережуваної OOO — розкласти її на суму операторів Паулі, O=∑iciPiO=\sum_i{c_i}{P_i}O=∑i​ci​Pi​, і окремо обчислити значення очікування кожного оператора Паулі, ⟨Pi⟩\langle P_i \rangle⟨Pi​⟩. Значення очікування спостережуваної, ⟨O⟩\langle O \rangle⟨O⟩, тоді є тією самою лінійною комбінацією значень очікування Паулі: ⟨O⟩=∑ici⟨Pi⟩{\langle O \rangle}=\sum_i{c_i}{\langle P_i \rangle}⟨O⟩=∑i​ci​⟨Pi​⟩. Якщо набір операторів Паулі комутують між собою, вимірювання, потрібні для обчислення їхніх значень очікування, можна виконувати одночасно. Коли ти запускаєш коло за допомогою функції LTM AI-QEM, функція використовує примітив Estimator, щоб запустити коло на обладнанні як зазвичай. Вона дотримується тієї самої процедури розкладання спостережуваної на оператори Паулі й окремого обчислення їхніх значень очікування. Потім GCN-Transformer, архітектура глибокого навчання, передбачає поправковий коефіцієнт ζi\zeta_iζi​ для кожного оператора Паулі PiP_iPi​. Функція використовує цей коефіцієнт, щоб скоригувати зашумлене значення очікування кожного оператора Паулі: ⟨Pi⟩mitigated=⟨Pi⟩noisyζi{\langle P_i \rangle}_{mitigated} = \frac{{\langle P_i \rangle}_{noisy}}{\zeta_i}⟨Pi​⟩mitigated​=ζi​⟨Pi​⟩noisy​​. Отже, пом'якшене значення очікування дорівнює ⟨O⟩mitigated=∑ici⟨Pi⟩mitigated=∑ici⟨Pi⟩noisyζi{\langle O \rangle}_{mitigated} = \sum_i{c_i}{\langle {P_i} \rangle}_{mitigated} = \sum_i{c_i}{\frac{{\langle P_i \rangle}_{noisy}}{\zeta_i}}⟨O⟩mitigated​=∑i​ci​⟨Pi​⟩mitigated​=∑i​ci​ζi​⟨Pi​⟩noisy​​.

Робочий процес використання функції LTM AI-QEM такий:

  1. Визнач свої кола та спостережувані.

  2. Запусти функцію LTM AI-QEM, передавши пари кола та спостережуваної як примітивні уніфіковані блоки (PUB).

  3. Отримай результати, що містять значення очікування спостережуваної щодо відповідного квантового кола в кожному PUB.

Багато тестових прикладів емпірично показують, що функція LTM AI-QEM покращує оцінку спостережуваних. Функція має такі особливості:

  • Експерименти корисного масштабу: тестові приклади показують, що AI-QEM працює краще за інші методи на основі ШІ для кіл великої глибини та великої ширини. Результати дивись у розділі Бенчмарки.

  • Примітив: функція підтримує примітив Estimator, тож ти можеш використовувати її для обчислення значення очікування будь-якої спостережуваної щодо будь-якого квантового кола.

  • Примітивний уніфікований блок (PUB): функція LTM AI-QEM підтримує всі типи PUB (тобто всі конфігурації кола та спостережуваної), які підтримує примітив Estimator.

Техніка AI-QEM починається з побудови набору даних, у якому випадкові квантові кола генеруються з різними налаштуваннями параметрів. Для кожного кола обчислюються як ідеальні значення очікування (отримані симуляцією), так і зашумлені значення очікування (отримані виконанням на обладнанні). Ці результати разом із відповідними квантовими колами та інформацією про бекенд зберігаються в сховищі набору даних. Потім набір даних використовується для навчання моделі машинного або глибокого навчання, що може пом'якшувати шум у квантових обчисленнях, а навчена модель зберігається для майбутнього використання. Під час виведення навчена модель отримує на вхід квантове коло, його зашумлене значення очікування, обчислене на обладнанні, відповідні спостережувані та інформацію про бекенд. Далі модель обробляє ці вхідні дані й видає значення очікування з пом'якшеним шумом.

Примітка: час CPU — це час постобробки. Три дзеркальні кола були надіслані разом в одному запуску, тому записані часи QPU і CPU стосуються всіх трьох кіл разом. Кожен запуск кола Кліффорда містив дев'ять PUB з різною глибиною кола, тому записані часи стосуються всіх дев'яти PUB разом. Кожен запуск кола Ізінга містив 10 PUB з різною кількістю кроків Троттера, тому записані часи стосуються всіх 10 PUB разом.

Для дзеркальних схем у бенчмарках використовуються ансаци RealAmplitudes, TwoLocal та EfficientSU2 з 30, 35 і 40 кубітами відповідно. Спостережувані складаються з одного оператора Паулі ZZZ на випадково вибраному кубіті з ідеальним очікуваним значенням 1.

Для схем Кліффорда в бенчмарках використовуються схеми з 50 і 100 кубітами, а спостережувані ініціалізуються як один або кілька випадково розташованих операторів Паулі ZZZ. Еволюція оператора збільшує вагу Паулі цих спостережуваних, що дає складніші спостережувані для бенчмаркінгу. Спостережувані побудовано так, щоб їхнє ідеальне очікуване значення дорівнювало 1, що незалежно перевіряється стабілізаторним моделюванням.

Для симуляцій тротеризованого гамільтоніана 2D моделі Ізінга з нахиленим полем (TFI) у бенчмарках використовуються три режими параметрів: малий кут (θX,θZ,θZZ)=(0.1,0.1,0.1)(\theta_X,\theta_Z,\theta_{ZZ})=(0.1,0.1,0.1)(θX​,θZ​,θZZ​)=(0.1,0.1,0.1), майже-Кліффордів (0.1,0.05,1.5708)(0.1,0.05,1.5708)(0.1,0.05,1.5708) і хаотичний (0.53,0.1,1.0)(0.53,0.1,1.0)(0.53,0.1,1.0). Спостережувана — це середня намагніченість,

OM=1M∑iZi,O_M = \frac{1}{M}\sum_i Z_i,OM​=M1​i∑​Zi​,

де MMM — кількість кубітів у симуляції. Ідеальні очікувані значення обчислюються методом розріджених динамік Паулі (SPD), тобто методом поширення Паулі, і перевіряються за симуляціями вектора стану Qiskit для схем із менш ніж 29 кубітами.

Для всіх бенчмарків точність мітигації обчислюється так:

Accuracy=(1−∣⟨O⟩ideal−⟨O⟩mitigated∣⟨O⟩ideal)×100%,\mathrm{Accuracy} = \left( 1- \frac{ \left|\langle O\rangle_{\mathrm{ideal}}-\langle O\rangle_{\mathrm{mitigated}}\right| }{ \langle O\rangle_{\mathrm{ideal}} } \right)\times100\%,Accuracy=(1−⟨O⟩ideal​∣⟨O⟩ideal​−⟨O⟩mitigated​∣​)×100%,

де ⟨O⟩ideal\langle O\rangle_{\mathrm{ideal}}⟨O⟩ideal​ і ⟨O⟩mitigated\langle O\rangle_{\mathrm{mitigated}}⟨O⟩mitigated​ — ідеальне та мітиговане очікувані значення відповідно.

Приклади​

Приклад 1: схема GHZ​

Цей приклад показує базовий робочий процес функції LTM AI-QEM на простій nnn-кубітній схемі GHZ і двочастинковому тензорному добутку спостережуваних ZiZjZ_iZ_jZi​Zj​, очікуване значення якого для стану GHZ відоме і дорівнює 1.

Побудова PUB​

Як і примітив Estimator, функція LTM AI-QEM приймає на вхід примітивні уніфіковані блоки (PUB). PUB — це кортеж виду (circuit, observables, parameter_values, precision), де parameter_values обов'язкове для параметричних схем, а precision необов'язкове.

Схема​

nnn-кубітний стан Грінбергера–Горна–Цайлінгера (GHZ) задається так:

∣GHZ⟩n=∣0⟩⊗n+∣1⟩⊗n2=∣00…0⟩⏞n qubits+∣11…1⟩⏞n qubits2.|GHZ\rangle_{n} = \frac{\vert{0}\rangle^{\otimes{n}} + \vert{1}\rangle^{\otimes{n}}}{\sqrt2} = \frac{\overbrace{\vert{00}\dots{0}\rangle}^{\text{$n$ qubits}} + \overbrace{\vert{11}\dots{1}\rangle}^{\text{$n$ qubits}}}{\sqrt2}.∣GHZ⟩n​=2​∣0⟩⊗n+∣1⟩⊗n​=2​∣00…0⟩​n qubits​+∣11…1⟩​n qubits​​.

Щоб побудувати nnn-кубітний стан GHZ, ініціалізуй усі кубіти в стані ∣0⟩|0\rangle∣0⟩ і застосуй вентиль Адамара до першого кубіта, щоб створити рівну суперпозицію. Потім застосуй послідовність вентилів CNOT по всьому регістру, де кубіт iii є керуючим, а кубіт i+1i+1i+1 — цільовим. Ця драбина заплутувальних вентилів поширює початкову суперпозицію на всі кубіти, що дає заплутаний стан GHZ.

Спостережувані​

Вимірювання двочастинкового тензорного добутку Zi⊗ZjZ_i \otimes Z_jZi​⊗Zj​ на стані GHZ оцінює кореляцію парності між будь-якими двома кубітами регістра. Оскільки стан GHZ є суперпозицією станів із самих нулів і самих одиниць, будь-які два кубіти ідеально корельовані. Власне значення дорівнює (+1×+1)=1(+1 \times +1) = 1(+1×+1)=1 для гілки ∣00…0⟩\vert00\dots0\rangle∣00…0⟩ і (−1×−1)=1(-1 \times -1) = 1(−1×−1)=1 для гілки ∣11…1⟩\vert11\dots1\rangle∣11…1⟩. Оскільки обидві гілки дають +1, теоретичне очікуване значення дорівнює 1. Побудуй спостережувану за допомогою класу SparsePauliOp.

Оскільки схема не є параметричною, побудуй PUB як (circuit, observable).

Приклад 2: дзеркальна схема​

Цей приклад використовує дзеркальну схему для обчислення очікуваних значень спостережуваних, переданих у PUB різних форм. Він демонструє функцію LTM AI-QEM та її сумісність із різними формами PUB і порівнює мітиговані результати з немітигованими.

Дзеркальна схема застосовує випадково згенеровану схему, а потім її обернену. В ідеальному виконанні без шуму обидві половини взаємно скасовуються і повертають кубіти до початкового стану. Через це схема корисна для вивчення того, як шум апаратного забезпечення та середовища виконання впливає на інакше передбачуваний результат.

У цьому прикладі ти будуєш кілька PUB. Кожен PUB поєднує одну й ту саму дзеркальну схему зі спостережуваними, складеними з операторів Паулі, які задано в різних формах.

Функція LTM AI-QEM обчислює ці спостережувані та повертає як очікувані значення із зашумленого виконання, так і значення після мітигації. Цей приклад має дві цілі: перевірити, що функція приймає підтримувані формати PUB, і порівняти мітиговані очікувані значення із зашумленими, щоб побачити, наскільки ефективно робочий процес мітигації помилок відновлює очікувану поведінку дзеркальної схеми.

import numpy as np
from qiskit.circuit.library import unitary_overlap
from qiskit.circuit.random import random_circuit
from qiskit.quantum_info import SparsePauliOp

def create_mirror_circuit(
    n_qubits: int, depth: int, seed: int = 42
) -> QuantumCircuit:
    """Generates an n-qubit random circuit followed by its inverse (mirror) and measure all qubits."""  # noqa: E501
    circuit = random_circuit(n_qubits, depth=depth, seed=seed)
    circuit.barrier()
    mirror_circuit = unitary_overlap(circuit, circuit)
    return mirror_circuit

Приклад 4: цегляна схема Кліффорда​

Цей приклад симулює схеми Кліффорда. Це сімейство схем корисне тим, що симуляцію можна спроєктувати так, щоб вона мала відоме очікуване значення. Зокрема, можна спроєктувати схему та спостережувану так, щоб очікуване значення завжди дорівнювало 1, як описано нижче:

  1. Відправна точка (стабілізатор): Почни з вакуумного стану ∣0⟩⊗n|0\rangle^{{\otimes}n}∣0⟩⊗n. Застосування оператора Паулі ZZZ або одиничного оператора до ∣0⟩|0\rangle∣0⟩ залишає його незмінним: Z∣0⟩=∣0⟩Z|0\rangle = |0\rangleZ∣0⟩=∣0⟩ і I∣0⟩=∣0⟩I |0\rangle = |0\rangleI∣0⟩=∣0⟩. Тому будь-який рядок Паулі PPP, що є тензорним добутком лише ZZZ та III, залишає стан із самих нулів ∣0⟩⊗n|0\rangle^{{\otimes}n}∣0⟩⊗n незмінним: P∣0⟩⊗n=∣0⟩⊗nP |0\rangle^{{\otimes}n} = |0\rangle^{{\otimes}n}P∣0⟩⊗n=∣0⟩⊗n.

  2. Еволюція Кліффорда: Застосування унітарного оператора ULU_LUL​ до стану дає ∣ψ⟩=UL∣0⟩⊗n|\psi\rangle = U_L |0\rangle^{{\otimes}n}∣ψ⟩=UL​∣0⟩⊗n. Щоб знайти спостережувану, очікуване значення якої для цього нового стану дорівнює 1, застосуй те саме унітарне перетворення до оператора: OL=ULPUL†O_L = U_L P U_L^{\dagger}OL​=UL​PUL†​. Це зображення Гайзенберга в квантовій механіці.

  3. Чому спостережувана залишається одним рядком Паулі: Якби ULU_LUL​ містив некліффордові вентилі (такі як вентилі T або довільні обертання), ULPUL†U_L P U_L^\daggerUL​PUL†​ розкладався б у суму багатьох різних рядків Паулі. Тобі довелося б вимірювати багато різних спостережуваних і додавати їх, щоб отримати 1. Однак, оскільки схема використовує лише вентилі Кліффорда, теорема Готтесмана–Нілла гарантує, що ULPUL†U_L P U_L^\daggerUL​PUL†​ відображається рівно в один рядок Паулі (наприклад, XY−ZXX Y -Z XXY−ZX).

  4. Математична гарантія: Завдяки такій побудові обчислення очікуваного значення зводиться до простої алгебричної підстановки:

⟨OL⟩=⟨ψ∣OL∣ψ⟩\langle O_L \rangle = \langle \psi | O_L | \psi \rangle⟨OL​⟩=⟨ψ∣OL​∣ψ⟩

Підстав ∣ψ⟩|\psi \rangle∣ψ⟩ і OLO_LOL​:

(⟨0∣⊗nUL†)(ULPUL†)(UL∣0⟩⊗n)(\langle 0 |^{\otimes n} U_L^{\dagger}) (U_L P U_L^{\dagger}) (U_L | 0 \rangle ^{\otimes n})(⟨0∣⊗nUL†​)(UL​PUL†​)(UL​∣0⟩⊗n)

Сусідні множники UL†ULU_L^\dagger U_LUL†​UL​ скорочуються (вони дорівнюють одиничному оператору III):

=⟨0∣⊗nP∣0⟩⊗n= \langle 0 |^{\otimes n} P | 0 \rangle ^{\otimes n}=⟨0∣⊗nP∣0⟩⊗n

Оскільки PPP є тензорним добутком лише ZZZ та III, P∣0⟩⊗n=∣0⟩⊗nP| 0 \rangle ^{\otimes n} = | 0 \rangle ^{\otimes n}P∣0⟩⊗n=∣0⟩⊗n, а отже:

=⟨0∣⊗n∣0⟩⊗n=1= \langle 0 |^{\otimes n} | 0 \rangle ^{\otimes n} = 1=⟨0∣⊗n∣0⟩⊗n=1

Спочатку спроєктуй квантові схеми, що містять лише вентилі Кліффорда: однокубітні вентилі HHH, SSS, XXX, YYY і ZZZ та двокубітний вентиль CZCZCZ. Функція create_brickwork_clifford приймає кількість кубітів (num_qubits) і depth як аргументи та повертає квантову схему Кліффорда із заданими кількістю кубітів і глибиною.

import random
from qiskit import QuantumCircuit
from qiskit.circuit.library import HGate, SGate, XGate, YGate, ZGate

def create_brickwork_clifford(num_qubits: int, depth: int = 2):
    def get_random_1q_gate():
        gates = [HGate(), SGate(), XGate(), YGate(), ZGate()]
        return random.choice(gates)

    circuit = QuantumCircuit(num_qubits)
    for layer_idx in range(depth):
        for qubit in range(num_qubits):
            circuit.append(get_random_1q_gate(), [qubit])

        # Add CZ Gate in brickwork pattern
        if layer_idx % 2 == 0:
            for qubit in range(0, num_qubits - 1, 2):
                circuit.cz(qubit, qubit + 1)
        else:
            for qubit in range(1, num_qubits - 1, 2):
                circuit.cz(qubit, qubit + 1)
    return circuit

import numpy as np

random.seed(42)
np.random.seed(42)

observables_list = []

# Choose two unique random positions for 'Z'
z_positions = random.sample(range(num_qubits), pauli_weight)

# Build the Pauli string
pauli_str = ["I"] * num_qubits
for pos in z_positions:
    pauli_str[pos] = "Z"
Z_n = Pauli("".join(pauli_str))

for depth in depth_list:

    circuits_list.append(circuit)

    # Get Clifford object for the circuit

    # Evolve Z^n by the Clifford (Heisenberg picture, default)

    # Convert to SparsePauliOp

    observables_list.append(transformed_operator)

  • Немітиговані: Необроблені очікувані значення, повернуті апаратним забезпеченням, показані зі смугами похибок розміру ±σ\pm\sigma±σ.

  • Мітиговані (AI-QEM): Очікувані значення після мітигації помилок, також показані зі смугами похибок.

  • Ідеальні (стабілізаторна симуляція): Очікуване значення без шуму, ⟨O⟩ideal=1\langle O \rangle_{\text{ideal}} = 1⟨O⟩ideal​=1, для всіх глибин.
