Онлайн-середовища для роботи

Окрім завантаження та встановлення Qiskit на локальній машині, є кілька варіантів для тих, хто воліє працювати в онлайн-середовищі розробки.

Деякі провайдери пропонують онлайн-середовища Jupyter з попередньо встановленим Qiskit для швидкого та зручного старту. До рекомендованих провайдерів належать хмарний провайдер OVHcloud і хмарна платформа розробки квантового програмного забезпечення qBraid.

Рекомендовані середовища для ноутбуків із попередньо встановленим Qiskit​

Додаткові онлайн-середовища для Jupyter-ноутбуків, зокрема IBM Watson® Studio, Google Colab і Microsoft Azure Machine Learning Studio, можна використовувати для роботи з Qiskit, дотримуючись відповідних інструкцій.

AI-ноутбуки OVHcloud​

Користувачі OVHcloud Public Cloud і OVHcloud Startup можуть використовувати квантові ноутбуки OVHcloud для доступу до Qiskit та відправки завдань на QPU IBM® за допомогою акаунту IBM Quantum® або IBM Cloud®. Щоб дізнатися більше, відвідай сторінку Документація та навчальні матеріали OVHcloud.

примітка

AI-ноутбуки OVHcloud недоступні в деяких регіонах, зокрема у Сполучених Штатах. Крім того, інтерфейс користувача може відрізнятися залежно від регіону.

Виконай такі кроки, щоб розпочати:

  1. Створи акаунт IBM Cloud.
  2. Налаштуй акаунт OVHcloud.
  3. Створи проєкт OVH Public Cloud.
  4. Виконай кроки у розділі Запустити перший AI Notebook, вибравши Qiskit як фреймворк.

qBraid Lab​

Користувачі Qiskit можуть використовувати попередньо налаштовані Python-середовища qBraid, дотримуючись цих інструкцій. Докладніше читай у документації qBraid.

  1. Зареєструй безкоштовний акаунт qBraid.
  2. Створи лабораторне середовище.
  3. Запусти qBraid Lab, натисни іконку ENVS праворуч, клацни + ADD у верхній частині нової бічної панелі та знайди Qiskit. Клацни на версію, яку хочеш використовувати, а потім натисни Install.
  4. Створи Jupyter-ноутбук, клацнувши Python 3 [Qiskit] у розділі Notebook.
  5. Ти можеш встановити будь-які додаткові Python-пакети (наприклад, Qiskit v1.2) у клітинці ноутбука, виконавши команду %pip install [package_name]. Докладніше читай у розділі Команди Pip (magic).

Додаткові середовища для ноутбуків для користувачів Qiskit​

Для платформ без попередньо налаштованого Qiskit інструкції з налаштування схожі, але тобі потрібно встановити Qiskit вручну. Ти створюєш акаунт, починаєш новий проєкт (або ноутбук чи робочий простір, залежно від платформи) і встановлюєш Qiskit.

IBM Watson Studio​

  1. Налаштуй безкоштовну пробну версію Watson Studio.
  2. Створи проєкт Watson Studio.
  3. Щоб встановити необхідні пакети та залежності Qiskit, відкрий новий ноутбук і виконай таку команду: 
    !pip install qiskit pylatexenc !yes | pip uninstall simplejson

Google Colab​

  1. Створи акаунт Google.
  2. Перейди на цільову сторінку Google Colab і увійди за допомогою свого акаунту Google.
  3. Створи ноутбук у Colab і встанови Qiskit, виконавши таку команду: 
    %pip install qiskit

Microsoft Azure Machine Learning Studio​

  1. Створи акаунт Azure.
  2. Створи робочий простір.
  3. Створи Jupyter-ноутбук у своєму робочому просторі.
  4. З ноутбука виконай цю команду для встановлення Qiskit: 
     %pip install qiskit
