Qiskit Functions

Липень 2026​

  • Нові попередні перевірки та нові методи backend у Qiskit Functions v0.17.0: Нові методи в qiskit-ibm-catalog дозволяють перевіряти ємність runtime та доступ до backend перед запуском, а run() тепер перевіряє обидва аспекти перед відправленням завдання.

    • Що нового

      • Коли ви викликаєте run() для функції, сервіс спочатку перевіряє три речі: чи має ваш instance ємність runtime, чи можете ви дістатися до названого вами backend, і чи доступний хоча б один backend. Якщо щось не так, ви одразу отримуєте зрозумілу помилку замість очікування в черзі.

        Ви також можете самостійно перевірити ці ресурси в будь-який час:

        • Перевірте свою залишкову ємність runtime за допомогою usage().

        • Отримайте список backend, до яких має доступ ваш instance, за допомогою backends().

        • Знайдіть окремий backend і підтвердьте доступ за допомогою backend().

        • Знайдіть backend з найменшою кількістю очікуваних завдань за допомогою least_busy().

    • Типові випадки використання

      • Перевірте свою залишкову ємність перед довгою партією завдань і пропустіть запуск, якщо її недостатньо для завершення.

      • Виберіть backend у коді замість жорсткого вказання назви.

      • Швидко завершуйте з помилкою у конвеєрах та ноутбуках замість очікування в черзі.

    • Початок роботи

      • Спочатку переконайтеся, що у вас встановлена остання версія qiskit-ibm-catalog:

        pip install --upgrade qiskit-ibm-catalog

      • Потім дивіться документацію для отримання додаткової інформації та прикладу.

2025​

Третій квартал

18 липня 2025​

Шаблони Qiskit Functions надають вам модульний конвеєр, який дозволяє замінювати нові інструменти, методи або конфігурації для власних експериментів. Усі шаблони функцій також легко розгортаються в Qiskit Serverless, де ви можете легко використовувати класичні обчислення як частину виконання свого робочого процесу. Ви можете розгорнути свій serverless-пакет у бажаному хмарному середовищі або скористатися розміщеним сервісом, наданим IBM для користувачів Premium та Flex Plan. Незалежно від обраного варіанту, Qiskit Serverless допомагає спростити виконання та розпаралелити частини вашого робочого процесу.

Відвідайте посібник шаблони Qiskit Functions, щоб дізнатися більше, або прочитайте огляд Qiskit Functions у документації.

Другий квартал

5 червня 2025​

  • Ми раді представити дві нові функції для фінансів та оптимізації:

    • QUICK-PDE від ColibriTD дозволяє користувачам розв'язувати певні диференціальні рівняння для задач деформації матеріалів та обчислювальної гідродинаміки. Наприклад, одна команда дослідників уже почала використовувати функцію QUICK-PDE для вивчення динаміки нових реактивних рідин, розроблених для більш ефективної передачі тепла в типі ядерного реактора, відомому як малі модульні реактори (Small Modular Reactors).

    • Quantum Portfolio Optimizer від Global Data Quantum дозволяє дослідникам кількісних фінансів проводити зворотне тестування стратегій оптимізації портфелів. Працюючи на понад 100 qubit, ця функція обчислює коефіцієнт Шарпа портфеля відносно прибутковості за вказаний період часу. Ранні користувачі досліджують здатність оптимізатора оцінювати історичну ефективність інвестиційної стратегії та порівнювати різні портфелі за подібних умов.

Перегляньте Каталог Qiskit Functions, щоб запросити безкоштовну пробну версію вже сьогодні.

16 травня 2025​

  • Протягом наступних тижнів кожна функція надаватиме детальну інформацію, яка допоможе вам запускати, налагоджувати та аналізувати ваші робочі процеси. Це включає:

    • Коли завдання завершуються невдало, ви можете використовувати job.error_message(), щоб знайти конкретні коди помилок та повідомлення, які допоможуть налагодити ваші робочі процеси

    • job.status() надаватиме більше інформації про те, що відбувається, поки функція перебуває в стані RUNNING, включно з:

      • RUNNING: MAPPING

      • RUNNING: OPTIMIZING_FOR_HARDWARE

      • RUNNING: WAITING_FOR_QPU

      • RUNNING: EXECUTING_QPU

      • RUNNING: POST_PROCESSING

    • Нарешті, після завершення Qiskit Function ви можете перевірити, скільки часу витрачено на кожному етапі, за допомогою job.result()['metadata']['resource_usage'], як показано в наступному прикладі.

Розгорнути для прикладу коду
{
      ...,
  "metadata": {
    "resource_usage": {
      {
        "RUNNING: MAPPING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: OPTIMIZING_FOR_HARDWARE": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: WAITING_FOR_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: EXECUTING_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: POST_PROCESSING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
      },
    }
  }
}

Ми сподіваємося, що ці зміни полегшать використання Qiskit Functions, і ви можете почати з безкоштовних пробних версій у каталозі вже сьогодні.

2024​

16 вересня 2024​

  • Представляємо попередню версію (preview) Qiskit Functions для користувачів IBM Quantum Premium Plan. Щоб почати, виконайте pip install qiskit-ibm-catalog та дослідіть документацію Qiskit Functions. За допомогою клієнта каталогу Qiskit Functions ви можете надсилати робочі навантаження до абстрагованих сервісів, розроблених для прискорення ваших досліджень. Увійдіть, використовуючи наявні облікові дані IBM Quantum Platform.

    Попередня версія Каталогу Qiskit Functions надає доступ користувачам Premium Plan для дослідження доступних функцій, включно з написаними IBM та написаними іншими учасниками нашої екосистеми. Каталог містить два види функцій: функції circuit та функції застосунків.

    • Функції circuit надають спрощений інтерфейс для запуску circuit. Вони отримують надані користувачем абстрактні circuit та спостережувані величини як вхідні дані, а потім керують синтезом, оптимізацією та виконанням репрезентативного ISA circuit. Функції circuit об'єднують найновіші можливості транспіляції, придушення похибок та пом'якшення похибок, щоб зробити продуктивність рівня утиліти доступною одразу з коробки. Це дозволяє обчислювальним науковцям зосередитися на відображенні своїх задач у circuit, а не на створенні шаблону для кожної задачі з нуля.

    • Функції застосунків охоплюють завдання вищого рівня, такі як дослідження алгоритмів та випадків використання, специфічних для певної галузі. Розробники підприємств та науковці з даних можуть не мати фонових знань з квантової інформаційної науки для роботи з circuit, а натомість сподіваються привнести свої галузеві знання для розвитку алгоритмів та застосунків квантових обчислень. За допомогою функцій застосунків користувачі можуть вводити свої класичні вхідні дані та отримувати рішення, щоб легше експериментувати з упровадженням квантових обчислень у свої галузеві робочі процеси.

  • З запуском Каталогу Qiskit Functions розробники Premium Plan можуть дослідити функцію IBM Circuit. Функція IBM Circuit включає найновіші розширення Qiskit на основі ШІ для синтезу, оптимізації та планування circuit, а також передові методи пом'якшення похибок для повернення максимально точних оцінок, можливих на сьогоднішньому обладнанні.

    Користувачі можуть придбати ліцензії на такі функції, надані нашими партнерами Q-CTRL, QEDMA та Algorithmiq.

  • Функції circuit

    • Q-CTRL випускає функцію circuit, яка застосовує керовані ШІ техніки квантового керування, за допомогою яких користувачі можуть успішно масштабуватися до більших задач.

    • Algorithmiq випускає функцію circuit, яка застосовує TEM (tensor-network error mitigation) — метод пом'якшення похибок для отримання оцінювачів з меншою кількістю shot, ніж метод PEC (probabilistic error cancellation).

    • QEDMA випускає функцію circuit, яка використовує власні протоколи для ефективної та точної характеризації зашумлених операцій QPU, і застосовує придушення та пом'якшення похибок на основі даних характеризації.

  • Функції застосунків

    • Q-CTRL випускає розв'язувач оптимізації, за допомогою якого користувачі можуть передати граф або цільову функцію та отримати вартості рішень.
