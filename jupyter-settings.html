⚙️ Налаштування doQumentation

Налаштуй сервер Jupyter, що використовується для виконання коду Python у туторіалах.

Current Environment: Не виявлено

Серверний бекенд

Обери бекенд для виконання коду:

Режим виконання

Обери, що відбувається при натисканні «Виконати» на сторінках туторіалів. Це стосується лише вбудованого виконання коду на цьому сайті — відкриття ноутбука в JupyterLab використовує стандартне Qiskit-середовище виконання.

Зміни набудуть чинності під час наступного сеансу ядра. Якщо код виконується, натисни «Назад», потім «Виконати» для застосування.

Акаунт IBM Quantum

Дотримуйся інструкцій нижче, щоб налаштувати доступ до IBM Quantum.
Примітка щодо безпеки: Облікові дані зберігаються у твоєму браузері у відкритому вигляді: в localStorage та, на doqumentation.org, у cookie, спільному для мовних сайтів. Вони не зашифровані, і їх можуть прочитати розширення браузера або будь-хто, хто має доступ до цього пристрою. Скористайся налаштуванням терміну дії нижче, щоб обмежити ризик, і видали облікові дані після завершення роботи. На спільних або публічних комп'ютерах краще використовуй описаний нижче ручний спосіб із save_account().

Введи свої облікові дані IBM Quantum тут один раз. Вони будуть автоматично підставлені через save_account() під час запуску ядра, тож не потрібно вводити їх у кожному ноутбуці. Це стосується лише вбудованого виконання коду на цьому сайті — щоб відкрити ноутбук у JupyterLab, потрібно викликати save_account() вручну.

  1. Зареєструйся at quantum.cloud.ibm.com/registration — no credit card required for the first 30 days
  2. Sign in at Екземпляри
  3. Instance — Create a free Open Plan instance at головна сторінка if you don't have one yet
  4. API Token — Click your profile icon (top right), then "API token". Copy the key.

For detailed steps, see IBM's Set up authentication guide (step 2).

Альтернатива: виконай save_account() вручну в комірці ноутбука

Якщо не хочеш зберігати облікові дані в цьому браузері, встав це в будь-яку комірку коду та виконай. Облікові дані зберігаються в тимчасовому сховищі ядра Binder і втрачаються після завершення сесії.

from qiskit_ibm_runtime import QiskitRuntimeService
QiskitRuntimeService.save_account(
    token="YOUR_API_TOKEN",
    instance="YOUR_CRN",
    overwrite=True
)

Попередньо обчислені виводи

Кожна сторінка ноутбука показує попередньо обчислені виводи (зображення, таблиці, текст) з початкових запусків IBM. Коли ти натискаєш Run, щоб виконати код наживо, показуються і оригінальні виводи, і твої нові результати. Вимкни цей перемикач, щоб приховати оригінальні виводи під час живого виконання, залишивши видимими лише твої результати.

Python-попередження

За замовчуванням Python-попередження (повідомлення про застарівання, підказки часу виконання) пригнічуються для чистішого виводу ноутбука. Вимкни це, щоб бачити всі попередження — корисно для налагодження або щоб дізнатися про зміни в API.

Дані та конфіденційність

Усі дані залишаються у твоєму браузері. На doqumentation.org вони зберігаються в localStorage та в cookie, які ділять їх між мовними сайтами; ці cookie надсилаються статичному вебхостингу з кожним запитом сторінки, але ніколи — на сервер doQumentation. Очищення даних браузера або використання іншого браузера/пристрою починає все з нуля.

Learning Progress

Відвідані сторінки показують ✓ на бічній панелі. Сторінки ноутбуків показують </>: сірий, доки не відвідано, синій після відвідування, зелений після того, як ти виконав на них код.

Прогрес ще не відстежується. Відвідай туторіали та посібники, щоб почати.

Розширені налаштування

IBM Cloud Code Engine

Підключи власний екземпляр Code Engine для виконання коду у хмарі.

Інструкції з налаштування
  1. Створи акаунт IBM Cloud на cloud.ibm.com (доступний безкоштовний тариф)
  2. Перейди до IBM Cloud Code Engine console і створи новий проект у потрібному регіоні
  3. Створи новий додаток із образом ghcr.io/janlahmann/doqumentation-codeengine:latest, порт прослуховування 8080
    Розмір: 1 vCPU / 2 ГБ для одного користувача, 8 vCPU / 16 ГБ для воркшопів (до 80 користувачів)
  4. Встанови змінні середовища: JUPYTER_TOKEN — захищений токен (мінімум 32 символи), CORS_ORIGIN — твій домен (наприклад, https://doqumentation.org)

Деталі щодо розміру для воркшопів дивись у документації з налаштування воркшопу.

Пакети Binder

Під час роботи на GitHub Pages код виконується через MyBinder. Середовище Binder містить попередньо встановлені основні пакети Qiskit:

qiskit[visualization], qiskit-aer,
qiskit-ibm-runtime, pylatexenc,
qiskit-ibm-catalog, qiskit-addon-utils, pyscf

Деякі ноутбуки потребують додаткових пакетів. Ти можеш встановити їх за потреби, виконавши це в комірці коду:

!pip install -q <package>

Або встанови всі необов'язкові пакети одразу:

!pip install -q scipy scikit-learn qiskit-ibm-transpiler \
  qiskit-experiments plotly sympy qiskit-serverless \
  qiskit-addon-sqd qiskit-addon-mpf \
  qiskit-addon-aqc-tensor[aer,quimb-jax] \
  qiskit-addon-obp qiskit-addon-cutting ffsim \
  gem-suite python-sat

Довідка з налаштування

Налаштування RasQberry

RasQberry запускає контейнер doQumentation (див. «Налаштування Docker» нижче). Відкрий сайт за адресою Pi, порт 8080, і код виконуватиметься на Pi без додаткового налаштування.

Налаштування локального Jupyter

Запусти сервер Jupyter, який приймає лише цей сайт, із токеном на твій вибір, а потім введи його URL і токен у розділі «Власний сервер» вище:

jupyter server --ServerApp.token='choose-a-long-token' \
  --ServerApp.allow_origin='https://doqumentation.org' \
  --ServerApp.disable_check_xsrf=True

Налаштування Docker

Контейнер Docker під час запуску генерує випадковий токен Jupyter. Виконання коду через сайт (порт 8080) працює автоматично — токен не потрібен. Токен потрібен лише для прямого доступу до JupyterLab на порту 8888.

Щоб отримати токен із журналів контейнера:

podman logs doq | grep "Jupyter token"

Щоб задати фіксований токен:

podman run -d --name doq --restart unless-stopped \
  -e JUPYTER_TOKEN=choose-a-token \
  -p 8080:80 -p 127.0.0.1:8888:8888 \
  ghcr.io/janlahmann/doqumentation:jupyter

Віддалений сервер

Для віддалених серверів переконайся, що CORS налаштовано на дозвіл підключень із цього сайту. Додай наступне до свого jupyter_server_config.py:

c.ServerApp.allow_origin = 'https://doqumentation.org'
c.ServerApp.allow_credentials = True
